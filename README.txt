예일유치원 홈페이지 v2
1. 기존 저장소 main 루트에 index.html, admin.html, common.js, style.css, content.js, README.txt를 업로드합니다. 기존 content.js에 작성한 글이 있다면 먼저 백업하고 새 형식으로 옮겨야 합니다. 이 버전은 초기 빈 게시판입니다.
2. 공개 주소: https://yeil2026.github.io/ ; 편집 도구: https://yeil2026.github.io/admin.html
3. 편집 도구에서 기본 설정이나 게시물을 작성하고 임시 저장한 뒤 content.js 다운로드 → GitHub main 루트에 같은 이름으로 업로드 → Commit changes. 브라우저 임시 저장은 공개되지 않습니다. 다른 기기에서 작업 전 최신 공개본을 불러오세요. 동시 편집은 지원하지 않습니다.
4. 사진/PDF는 작은 파일(각 2MB 이하)을 직접 등록할 수 있지만 content.js가 커지므로 실제 운영에서는 GitHub에 images/ documents/ videos/ 파일을 별도 업로드한 후 상대 경로를 입력하세요. GitHub 웹 업로드 한도에 유의하세요. 유튜브 공개 또는 공유 가능한 영상 주소를 권장합니다. 블로그·인스타 자동 동기화는 없습니다.
5. 모든 저장소 파일 및 변경 이력은 공개될 수 있습니다. 유아 사진은 공개 동의 범위 확인, 운영위원회 자료는 개인정보 제거 후 공개용만 사용. 관리자 로그인/서버/CMS는 없으며 GitHub 계정 권한이 실제 배포 권한입니다. 임시 작성 자료는 브라우저에 남을 수 있습니다.
