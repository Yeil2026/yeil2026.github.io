예일유치원 홈페이지 사용 안내
1. index.html과 content.js를 깃허브 저장소 최상위에 함께 올립니다.
2. content.js의 // 로 시작하는 예시 행은 화면에 나타나지 않습니다. 실제 내용을 넣고 행 앞 // 를 제거하면 표시됩니다. 각 항목 끝 쉼표를 유지하세요.
3. 사진은 images/파일명.jpg, PDF는 documents/파일명.pdf, 영상은 videos/파일명.mp4 경로로 올린 후 content.js에 같은 경로를 기재합니다. 폴더는 필요한 때 생성합니다.
4. 블로그와 인스타그램 전체 URL을 따옴표 안에 넣습니다. 블로그 게시글은 posts에 직접 등록하며 자동 동기화하지 않습니다.
5. 유튜브 영상 ID는 watch?v= 뒤의 값입니다. 외부 삽입이 허용된 영상이어야 합니다.
6. GitHub Pages는 공개 사이트입니다. 유아 개인정보, 비공개 회의록, 동의 없는 얼굴 사진 등을 올리지 않습니다.
